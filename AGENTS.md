# Prototype Instructions

Run the local server yourself and open the preview in the browser available to this environment. Do not give the user server-start instructions when you can run it.

Before making substantial visual changes, use the Product Design plugin's `get-context` skill when the visual source is unclear or no longer matches the current goal. When the user gives durable prototype-specific design feedback, preferences, or decisions, record them in `AGENTS.md`.

When implementing from a selected generated mock, treat that image as the source of truth for layout, component anatomy, density, spacing, color, typography, visible content, and hierarchy.

Build app UI in `src/`. Keep `.openai/hosting.json`, `worker/index.js`, `scripts/prepare-sites-build.mjs`, and `tests/sites-worker.test.mjs` intact so the same local prototype can be handed to Sites. Before a Sites handoff, run `npm run build` and `npm run test:sites`; the build must leave `dist/client/index.html`, `dist/server/index.js`, and `dist/.openai/hosting.json`.

## Prototype-specific decisions

- Главный экран занимает один viewport: зацикленное фоновое видео с `object-fit: cover`, стеклянная навигация и статичная центральная типографика с CTA.
- Круглые контейнеры иконок, кнопки хедера и навигация программы используют один общий лёгкий стеклянный токен: почти прозрачная тёплая бело-серая подложка `rgba(214, 211, 207, 0.045)`, мягкий `backdrop-filter: blur(4px) saturate(105%)`, без обводки и без растровой подложки; финальная CTA остаётся примерно `70%` прежнего размера, но имеет сплошную коричневую заливку.
- Сразу после видеосцены расположен полноэкранный блок-манифест: три крупные смысловые строки и цитата К. Г. Юнга на затемнённом и размытом стоп-кадре из мастер-видео. Текст появляется последовательным мягким focus/clip-reveal, фон движется с лёгким параллаксом; при reduced motion остаётся простое плавное появление.
- Сразу после манифеста расположен тёмный блок «Для кого этот практикум»: широкая типографика `Unbounded`, семь строк с бронзовой нумерацией и разделителями, а слева — сгенерированный вертикальный editorial-образ женщины со стеклянной ДНК в чёрно-бронзовой палитре. На десктопе изображение остаётся sticky, на мобильном становится верхней частью одноколоночного потока; элементы мягко проявляются по мере скролла, reduced motion получает обычный fade.
- После блока аудитории идёт «Матрица решений: 3 дня, 7 уроков»: три чередующиеся сцены с ImageGen-иллюстрациями, точным текстом программы, липкой стеклянной навигацией по дням и GSAP-проявлением/параллаксом. На мобильном каждая сцена превращается в одноколоночную композицию.
- Фон секции программы с тремя фотографиями использует тот же коричневый токен `var(--cocoa)`, что и секция «Курс проводит лично Константин Александрович».
- Три фотографии дней программы берутся из локального референсного проекта `http://127.0.0.1:3001/`: винтовая лестница, архитектурный бетон в тёплом свете и фактура слоёв бумаги; они сохранены как `public/assets/program-day-1.png`, `program-day-2.png`, `program-day-3.png`.
- Блок программы анимируется сдержанно: секция получает едва заметное движение фонового света, заголовок, вводный текст и дни мягко проявляются при прокрутке, а фотографии медленно дрейфуют и слегка приподнимаются с бликом при наведении; при `prefers-reduced-motion` все движения отключаются.
- Весь контент сайта использует единый плавный scroll-reveal: заголовки, тексты, карточки, фотографии, списки, CTA и футер проявляются снизу с лёгким blur и коротким последовательным stagger внутри группы; элементы анимируются один раз, а при `prefers-reduced-motion` сразу показываются без движения.
- Хедер не участвует в scroll-reveal: его постоянное CSS-смещение `translateX(-50%)` сохраняется неизменным, чтобы навигация всегда оставалась строго по центру экрана.
- Четыре карточки результатов на десктопе остаются в одной строке, но используют расширенную сетку до `1500px`, компактные внутренние отступы и уменьшенную вертикальную высоту; описания сохраняют размер `22px`.
- В списке «Это наиболее полезно тем, кто» круглые иконки слева имеют размер `74px` на десктопе и `60px` на мобильном, под них выделена расширенная отдельная колонка.
- Следом размещён тёмный блок «Как всё проходит»: крупные показатели `3 / 7` и четыре пункта формата без карточной перегрузки.
- Блок автора использует портрет из пользовательского референса, крупный заголовок, биографию и список компетенций; названия компетенций набираются крупной прямой антиквой `32px` без курсива и всегда визуально доминируют над поясняющим текстом `22px`.
- Финальный блок содержит крупный призыв, сплошную коричневую CTA на Telegram, компактный футер и рабочую навигацию по разделам.
- У стеклянных кнопок нет видимой обводки.
- Типографическая пара — вариативные `Unbounded` и `Manrope` с кириллицей: широкие заголовки набираются жирным `Unbounded`, интерфейс и основной текст — читаемым `Manrope`.
- Основная палитра сайта собрана из приглушённых пудрово-коричневых оттенков по пользовательским референсам: `#b8967d`, `#906c60` и градиент `#7b5348` → `#9e7b6b` → `#b0907a`; светлый оттенок используется для акцентов, а тёмные — для фонов.
- Главный экран больше не управляет видео прокруткой: `hero-background.mp4` автоматически воспроизводится по кругу как обычный фон; hero занимает один экран, после которого сразу идёт манифест.
- Типографическая палитра — тёплая и высококонтрастная: молочный `#fffaf7` для заголовков, `#f5ebe5` для основного текста, `#e7d5c9` для метаданных и шампань `#ffe7d5` для акцентов; на светлых пудровых фонах под текстом используется лёгкое тёмное тонирование.
- Все заголовки `h1–h3` выравниваются по центру; абзацы, списки, подписи, цитаты и служебные тексты — по левому краю.
- Размеры типографики собраны в две шкалы: все смысловые `h2–h3` используют `--font-heading`, а поясняющие подзаголовки и описания под ними во всех секциях и на всех ширинах используют единый токен `--font-subtitle: 22px`; главный титул `h1` остаётся display-исключением.
- Все заголовки и крупные акцентные цифры набираются контрастной кириллической антиквой `Prata`, подобранной по пользовательскому референсу; повествовательный текст и UI остаются в `Manrope`.
- Контент и порядок секций следуют пяти скриншотам-скелетам от 01.08.2026: вводная, аудитория, результаты, программа 3 дня / 7 уроков, формат, автор, кейс, отзывы, контакты и юридический футер; белый документный вид референса не копируется, контент адаптируется в текущую пудрово-коричневую систему.
- Служебные номера секций и рубрики вида `01 · ...` на сайте не показываются; на иллюстрациях программы остаётся только лаконичная нумерация `01`, `02`, `03`.
- Заголовки дней имеют зафиксированные смысловые переносы: `Где я?` / `Ревизия и цена моих ошибок` и `Иллюзия контроля.` / `Сколько можно тянуть на себе?`.
- Вводный блок «Пора вернуть себе управление собственной жизнью» вместе с портретом, авторским текстом и цитатой использует чисто-белый фон и тёмную типографику.
- Единственная актуальная фотография автора на сайте — `public/assets/author-konstantin.jpg`, переданная пользователем 01.08.2026; она используется во всех авторских блоках вместо прежнего сгенерированного портрета.
- В блоке отзывов используются дословные тексты трёх подлинных Telegram-отзывов, переданных пользователем 01.08.2026; сами скриншоты удалены. На десктопе отзывы представлены тремя карточками в центральной горизонтальной строке с лёгким увеличением при наведении, а по клику полный текст открывается в крупном модальном окне; на мобильном карточки остаются горизонтальной прокручиваемой лентой.
- Пять скриншотов-скелетов от 01.08.2026 являются буквальным источником видимого текста, пунктуации, кавычек и порядка блоков сверху вниз; редакторские исправления вида `партнёрство`, `трёхдневный`, замена `Анти - грабли` на вариант с длинным тире и другие перефразировки запрещены.
