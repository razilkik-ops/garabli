# Prototype Instructions

Run the local server yourself and open the preview in the browser available to this environment. Do not give the user server-start instructions when you can run it.

Before making substantial visual changes, use the Product Design plugin's `get-context` skill when the visual source is unclear or no longer matches the current goal. When the user gives durable prototype-specific design feedback, preferences, or decisions, record them in `AGENTS.md`.

When implementing from a selected generated mock, treat that image as the source of truth for layout, component anatomy, density, spacing, color, typography, visible content, and hierarchy.

Build app UI in `src/`. Keep `.openai/hosting.json`, `worker/index.js`, `scripts/prepare-sites-build.mjs`, and `tests/sites-worker.test.mjs` intact so the same local prototype can be handed to Sites. Before a Sites handoff, run `npm run build` and `npm run test:sites`; the build must leave `dist/client/index.html`, `dist/server/index.js`, and `dist/.openai/hosting.json`.

## Prototype-specific decisions

- Главный экран повторяет композицию референса: полноширинное видео 16:9 без обрезки, тёмная стеклянная навигация, крупная центральная типографика.
- При нулевом скролле видны только первый кадр видео и анимированная подсказка; хедер, текст и CTA полностью скрыты.
- Главный экран — скролл-история: «Антиграбли» → «Трёхдневный практикум “Выйди из круга”» → четыре результата → финальный CTA. Все сцены и элементы хедера входят одним общим ярким RGB-глитчем и резко улетают перед следующей сценой.
- Четыре результата используют тексты из пользовательских референсов: «Абсолютная ясность», «Внутренняя опора», «Выход из вечного ожидания», «Пошаговый алгоритм».
- У результатов нет карточек: над центрированными заголовком и подтекстом расположена иконка Phosphor в круглом заблюренном стеклянном контейнере.
- Круглые контейнеры иконок, финальная кнопка «Принять участие», кнопки хедера и навигация программы используют один общий лёгкий стеклянный токен: почти прозрачная тёплая бело-серая подложка `rgba(214, 211, 207, 0.045)`, мягкий `backdrop-filter: blur(4px) saturate(105%)`, без обводки и без растровой подложки; финальная CTA остаётся примерно `70%` прежнего размера.
- Сразу после видеосцены расположен полноэкранный блок-манифест: три крупные смысловые строки и цитата К. Г. Юнга на затемнённом и размытом стоп-кадре из мастер-видео. Текст появляется последовательным мягким focus/clip-reveal, фон движется с лёгким параллаксом; при reduced motion остаётся простое плавное появление.
- Сразу после манифеста расположен тёмный блок «Для кого этот практикум»: широкая типографика `Unbounded`, семь строк с бронзовой нумерацией и разделителями, а слева — сгенерированный вертикальный editorial-образ женщины со стеклянной ДНК в чёрно-бронзовой палитре. На десктопе изображение остаётся sticky, на мобильном становится верхней частью одноколоночного потока; элементы мягко проявляются по мере скролла, reduced motion получает обычный fade.
- После блока аудитории идёт «Матрица решений: 3 дня, 7 уроков»: три чередующиеся сцены с ImageGen-иллюстрациями, точным текстом программы, липкой стеклянной навигацией по дням и GSAP-проявлением/параллаксом. На мобильном каждая сцена превращается в одноколоночную композицию.
- Следом размещён тёмный блок «Как всё проходит»: крупные показатели `3 / 7` и четыре пункта формата без карточной перегрузки.
- Блок автора использует портрет из пользовательского референса, крупный заголовок `Unbounded`, биографию, список компетенций и кейс из практики.
- Финальный блок содержит крупный призыв, стеклянную CTA на Telegram, компактный футер и рабочую навигацию по разделам.
- Навигация хедера появляется только после смысловых сцен, по одной кнопке с глитчем; кнопки дополнены иконками Phosphor.
- Видео начинается вплотную от верхнего края видимой области; свободное пространство из-за сохранения формата 16:9 остаётся только снизу.
- Линия прогресса привязана к фактической нижней границе полноширинного видео `16:9` через `top: min(56.25vw, 100%)`, а не к нижней границе viewport, поэтому между видео и линией нет чёрного зазора.
- У стеклянных кнопок нет видимой обводки.
- Для плавной двусторонней прокрутки используется `hero-scrub.mp4` с ключевым кадром каждые 6 кадров; стандартный последовательный seek сохраняется, но при смене направления скролла выполняется один немедленный seek к обратной позиции, чтобы видео гарантированно перематывалось назад без залипания.
- Текущий мастер видео — `IMG_5501.MP4`: `2560 × 1440`, `60fps`, около `10s`; браузерная версия сохраняет это разрешение и подключается с cache-buster `v=5501`.
- Типографическая пара — вариативные `Unbounded` и `Manrope` с кириллицей: широкие заголовки набираются жирным `Unbounded`, интерфейс и основной текст — читаемым `Manrope`.
- На первом кадре подсказка о скролле расположена по центру видео и исчезает до появления первого титра.
- Титр «Антиграбли» в своей сцене смещён на `30px` вверх относительно базового центра.
- `.glitch-reveal` использует тот же единый яркий RGB-глитч, что и сцены и навигация: короткие X/Y-сдвиги, насыщенные cyan/magenta-тени и краткий blur, затем полностью стабильный текст; анимация запускается один раз, а при reduced motion используется простое плавное появление.
- Финальная кнопка «Принять участие» в видеосцене использует в точности тот же класс и визуальный стиль, что и кнопки хедера: одинаковые размеры, типографику, стеклянный токен, тени, blur, интервалы и интерактивные состояния.
